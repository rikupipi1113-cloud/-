# 初回公開用同期

GitHub側mainの既存2コミットとREADMEを保持し、その上へ研究環境の公開用スナップショットを追加します。
原本の研究履歴と非公開の環境証跡はローカルで保持しています。個人情報を含む原本コミットは送信しません。

公開対象は研究コード、Python/Lean設定、研究状態、全41件のテスト、継承・査読プロトコル、
第1・第2段階の必要な報告、最終3サイクルの追記履歴と全文証拠です。
除外・匿名化したパスはpublication_manifest.jsonに記録しています。

生コマンドログ、端末詳細、コネクタの個人メタデータ、ローカル実行パスを含む診断JSON、
生成bundle、依存インストーラ、開発途中の模擬履歴を公開対象から除外しました。
文書の配置パスとJUnit hostnameを匿名化しました。参照される非公開ログの原本はローカルに残ります。
.venv、.tools、Lean .lakeキャッシュ、秘密情報ファイル、生成archiveはignore対象です。

既知のアクセストークン形式、秘密鍵、認証付きURL、認証値代入、email、ローカル識別子、
追跡ファイルサイズと履歴を検査しました。検査は未知の秘密情報が存在しないことの形式的保証ではありません。
公開用スナップショットの全41テストが成功しました。
実ChatGPT往復は未実証で、本番スケジュールは未登録・無効です。
